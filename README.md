# 知识收件箱

在电脑上把剪贴板里的文字或链接收进一个 Markdown 文件，再用本机页面搜索。不连接微信。

网上的页面发布在 GitHub Pages，电脑关机后仍能打开。别人打开页面并允许读取剪贴板后，在其他地方复制文字会弹出询问，可以选择保存或不保存。这些内容只保存在他自己的浏览器里，不会上传到仓库。

## 别人拿到之后怎么用

把整个 `知识收件箱` 文件夹拷走，不要带里面的 `.venv`（那是这台电脑自己生成的运行环境）。需要先安装 [Python 3.10 或更高版本](https://www.python.org/downloads/)，安装时勾选 **Add python.exe to PATH**。

- Windows：双击 `启动.bat`
- macOS / Linux：在终端执行 `sh 启动.sh`。Linux 还需要系统里有 `python3-tk`，以及 `wl-clipboard` 或 `xclip`

第一次运行会自动安装依赖，需要联网，可能要一两分钟。之后会留下一个小窗口，并打开搜索页。黑色窗口可以关掉，小窗口要留着。

## 收录

1. 复制一段文字，或一条 `http` / `https` 链接。
2. 小窗口会弹出询问。选「保存」或「不保存」。也可以按 `Ctrl+Alt+K` 再问一次。
3. 标签可以不填，例如 `工作 灵感`。

只打开网页、没有运行这个程序时：在页面上点「开启复制询问」，并允许读取剪贴板。之后在别的地方复制，这个页面开着就会弹出同样的询问。Chrome 还会尽量留一个浮在前面的小窗口。

同一条链接不会重复写入。再次收录时如果带了新标签，会补到原来那条上。快捷键按不出来时，用窗口上的「收录剪贴板」。

快捷键可以改：打开程序目录里的 `settings.json`，把 `hotkey` 改成例如 `"<ctrl>+<shift>+k"`，保存后重新打开程序。

## 搜索

浏览器打开窗口上显示的地址，默认是 `http://127.0.0.1:8765`。可以搜正文、链接和标签。点标签是「同时包含这些标签」。

笔记在同一目录的 `knowledge.md`。换电脑时把这个文件一起拷走。正文和「标签」那一行可以直接改；每条笔记头尾的 `<!-- kb ... -->` 要留下。

## 第一版不做的事

- 不收录截图和剪贴板里的图片。
- 收不到手机微信里的收藏。内容要先到这台电脑的剪贴板。
- 关掉小窗口后，本机快捷键会停。网上的页面仍可打开，每位访问者只能看到自己保存在本地的内容。

程序只监听本机 `127.0.0.1`。日志在 `inbox.log`，里面不记录剪贴板原文。
